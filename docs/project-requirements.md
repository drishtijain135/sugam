# SUGAM - Project Requirements

## Project Name
SUGAM

## Problem
Public transport information is fragmented. Users need separate platforms for buses, metro, and autos.

## Solution
SUGAM is a unified public transport route planner that combines bus, metro, and auto options in one place.

## Core Features
1. Multi-modal route planner
2. Crowdsourced live bus tracking
3. Seat availability predictor
4. Nearby stops
5. User authentication
6. Admin bus and route management

## Tech Stack
- Frontend: React.js + Vite + Tailwind CSS
- Backend: Node.js + Express.js
- Database: PostgreSQL
- Real-time: Socket.io
- Maps: Leaflet.js + OpenStreetMap
- Authentication: JWT + bcrypt
- Deployment: Vercel + Render

## MVP Goal
Build a working web app where users can search public transport routes, view buses on a map, share live bus location, and check seat availability.
